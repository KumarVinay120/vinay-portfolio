# Vinay Kumar — Data Analyst Portfolio

A responsive, modern dark portfolio website built with plain HTML, CSS, and JavaScript. No Node.js, React, database, or paid tools required.

## Files
- `index.html` — page content and sections
- `style.css` — layout, responsive styles, and visual design
- `script.js` — mobile navigation, copyright year, and copy-email button

## Open the website on your laptop
1. Extract `vinay-portfolio.zip`.
2. Open the `vinay-portfolio` folder in Visual Studio Code.
3. Open `index.html` in your browser, or install the free **Live Server** extension in VS Code and choose **Open with Live Server**.

## Before publishing
- Add your real LinkedIn and GitHub URLs.
- Replace the planned project cards with completed projects, screenshots, datasets, and truthful findings.
- Adjust skill levels to match your current ability.
- Check your contact email and profile information.

## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com/.
2. Create a public repository named `vinay-portfolio`.
3. Upload `index.html`, `style.css`, and `script.js` (and optionally this README).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The live URL will appear in Settings → Pages.

## Important
The dashboard numbers in the hero graphic are illustrative design examples, not verified results. The project cards are labelled as planned learning projects. Do not present them as completed work until you have done the analysis and added evidence.
